# Job Posting: Full-Stack .NET Developer (CourseApplication)

**Company:** CanarysPlayground  
**Location:** Remote (UTC-5 to UTC+5 overlap preferred)  
**Employment Type:** Full-time  
**Experience Level:** Mid-Senior  

## About the Role
We are looking for a Full-Stack .NET Developer to help build and evolve CourseApplication, a modern course registration platform. You will collaborate with product, design, and engineering to deliver secure, scalable features across the API and web UI.

## Responsibilities
- Build and maintain .NET 8 APIs using clean architecture principles.
- Develop responsive front-end features aligned with UX requirements.
- Implement secure authentication, authorization, and input validation.
- Write unit and integration tests with high coverage.
- Review code, improve performance, and address security findings.
- Collaborate on CI/CD and operational readiness.

## Required Qualifications
- 3+ years of professional experience with .NET (C#) and REST APIs.
- Strong understanding of ASP.NET Core, EF Core, and SQL.
- Front-end experience with modern frameworks (React preferred).
- Experience with Git-based workflows and code reviews.
- Familiarity with testing practices and CI pipelines.

## Preferred Qualifications
- Experience with clean architecture and domain-driven design.
- Knowledge of Azure services (App Service, SQL, Key Vault, Application Insights).
- Experience with containerization and Kubernetes.
- Background in security best practices and threat mitigation.

- Learning and certification budget.
- Modern tooling and development practices.
